What is the WBO Tech Suite?

Working by Outcomes (WBO) is a cornerstone element of our operating model, essential for realizing the One Pharma Strategy (OPS). By enabling greater focus and collaboration, WBO aims to minimize "energetic cost" while maximizing positive patient, societal, and business impact.

The WBO Tech Suite is the technology platform that makes this framework live and actionable. It replaces a fragmented ecosystem of Google Slides, Sheets, Trello, and Tableau with a single "one source of truth" on monday.com and Airtable for Middle East and North Africa countries.

💡 The Tech Suite is not just another tool — it's your engine for growth and global collaboration.

Update: New Validation for Task Completion

🗂️ Board: All Affiliate boards 📅 Effective: August 5, 2026

What Changed

A new validation has been added to the Work Package Status column. From now on, a WP cannot be marked as "Completed" unless at least one of the following fields is filled in:

🔗
Link to Working Folder

The shared folder where active work files are stored

🔗
Final Output Link

The link to the delivered or published output

Why This Matters

This validation ensures that every completed Work Package is properly documented and traceable. No WP should close without a reference to where the work lives — making it easier to audit, reuse, or hand off deliverables in the future.

What You Need to Do

Before setting any WP to Completed, make sure at least one of the links above is provided in the task record.

✅

Either link is sufficient — you don't need both.

⚠️

If you encounter a WP that was previously marked as Completed without a link, please update it at your earliest convenience.

📦

New: Work Package Archive Process

✓ ROLLING OUT NOW

We've introduced a new Archive feature to help keep your Work Package boards clean and focused on active work. Work Packages can be archived in two ways:

🔄
Automatic Archiving

A Work Package will be automatically archived 1 year after its completion date. No action needed — this keeps your boards tidy over time without manual effort.

✋
Manual Archiving

You can also manually archive a Work Package at any time, as long as the following conditions are met:

  • ✓The Work Package Status is set to Completed or Cancelled
  • ✓The "Are you sure?" confirmation is filled in

This validation ensures only properly closed Work Packages are archived, preventing accidental archiving of active work.

📂 Where do archived Work Packages go?
Each region has a dedicated Archive – Work Package Overview board (e.g. [LATAM] Archive – Work Package Overview) where archived items are stored for reference and historical tracking.

💡

Archived Work Packages remain fully accessible — they are simply moved out of the active board to keep your workspace organised.
